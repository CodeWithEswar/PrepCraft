# Interview preparation evidence

The view reads persisted mock metadata backed by terminal Execution records. It does not call the fixture-returning Mock UI loader. Duplicate mock/session-item metadata is deduplicated against Execution identities. Duration uses Execution's start, end and accumulated pauses.

Comparable configurations share blueprint/version, mode, evaluation policy, policy snapshot and ordered content-type/difficulty profile. Incompatible configurations are separate selectable groups. Small groups remain descriptive observations, not improvement claims. Titles are presentation text, never identity keys.

Existing stored review facets are client-writable self-reports. Their provenance remains `self_reported`; arbitrary stored strings and private snapshot content are not transported. Missing communication or other dimensions stay `not_evaluated`, not zero. Server-evaluated Learning bindings are the only objective correctness source.

Phase Flow allocates time only for sessions with recorded phase transitions, using the shared pause-adjusted elapsed clock. No phase allocation or communication judgment is inferred from code length or timestamps alone.

OA answered and unanswered counts are not accuracy. Behavioral cue use, retelling and confidence are explicitly self-practice observations. No hiring probability, automated communication quality, tracker success trend or Readiness snapshot is fabricated.
