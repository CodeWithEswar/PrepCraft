# Aptitude

Structured quantitative coverage includes numbers, percentages, ratio/proportion, averages, profit/loss, interest, work rates, speed/distance, counting, probability, algebra, geometry and mensuration. Logical reasoning, verbal ability and data interpretation have explicit outline topics.

Release 1 publishes prime/composite numbers, successive percentage change, division in a ratio, combined work rates and average speed. Numeric checks use exact server-side numeric comparison; choices use private answer keys. Suggested time is an activity-specific estimate, not a global performance baseline. Practice may pause; timed drills use server deadlines and reject late answer changes.

Solution Fold exposes the answer and reasoning only after confirmed submission. Missing lesson content is marked planned. Broader coverage is not represented as completed curriculum.
