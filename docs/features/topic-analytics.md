# Topic evidence explorer

Topics are attributed through canonical Execution/Learning/Revision identities. Display names are not fuzzy-matched into the curriculum. Unmapped time remains visible. The bounded topic list includes sample counts and median timing, with a search field and full evidence sheet.

The sheet combines selected-period timing/assistance, recorded targets, current Revision load and qualitative states from canonical Mastery. It states the independent current Mastery window. Missing evidence is not a weak topic.

The relationship list uses explicit topic/pattern pairs. Desktop users can opt into a lazy D3 map, capped at forty nodes and sixty edges. Mobile keeps the labeled table as primary content. Node buttons expose selection by keyboard; the SVG is an explained image, not an inaccessible control surface. Connections are observed associations, not prerequisites or causal dependence.

Actions reuse Practice's canonical topic launch contract and Planning's explicit-save editor. Unmapped items cannot create a canonical topic recommendation or plan shortcut.
