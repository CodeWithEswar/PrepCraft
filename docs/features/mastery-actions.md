# Highest-Leverage Actions

Every meaningful finding and missing dimension links to its owning feature. Supported weaknesses take precedence over evidence gaps. Internal ranking prioritizes evidence confidence (Strong 300, Moderate 200), high severity (40 versus 20), curriculum priority (core 30/high 20/medium 10/low 5/optional 0), required status (+5), and a bounded 25-point repetition penalty for evidence in the last two hours. Ties use stable entity identity. These weights are not shown as a user score.

Practice recommendations open the existing Execution lobby, with an explicit canonical topic where available. Timing gaps open single-question Interview practice; ordinary Practice targets are advisory. Revision recommendations open an owned due item or the authoritative queue. The user chooses the question; no unseen-question catalog or time estimate is invented.

Today consumes supported focus opportunities through the public Mastery server contract and surfaces an attention link without creating a task or readiness score. Rest plans are respected. A failed Mastery provider cannot block Today's task execution. Execution debriefs invalidate the affected workspace/user Mastery cache. Revision change signals refresh the same scope only.
