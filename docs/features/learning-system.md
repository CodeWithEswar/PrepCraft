# Learn

Learn unifies Aptitude, Java, SQL/DBMS, Operating Systems and Networks at /w/[workspaceSlug]/learn. The screenshot guides composition: journey, subject tracks, topic path and contextual Concept Lens. Graphite/mineral surfaces use Smoked Sienna and Hugeicons through AppIcon. Tablet/mobile use a modal drawer.

Release 1 has 25 original published concepts/checks, five per subject, across 67 structured topics. Another 782 concept outline entries are explicitly planned, not published lessons. These counts are coverage, never mastery. No streak, readiness, enrollment or completion figures are fabricated.

The server composes initial curriculum and lesson reading. Interactive search and detail use scoped TanStack keys including workspace/user and selection. Catalog reads are bounded (80 topics, 60 concepts plus lookahead); full lesson/activity retrieval is progressive. Learning Locker retrieves owned bookmarks across subjects.

Reading visits, bookmarks and notes are learning state. Objective assessment is evaluated in PostgreSQL against private answer keys, then committed through the existing Execution lifecycle. The same question_attempts, attempt outbox, Revision schedule and Mastery interpretation are reused. Answers are not present in pre-submit browser responses.

Today consumes at most two recent concept links. Planning opens its normal task editor with a concept-derived title and requires explicit save. Learning never writes another domain’s tasks or interprets its own mastery score.

The real Mistake Journal domain is not implemented in this repository. Learning captures optional controlled, self-reported tags on the shared attempt/outbox; it does not invent an aggregate journal or infer a diagnosis from an incorrect answer.

Java execution remains unavailable until a sandboxed external runner is configured. The local PostgreSQL lab is exploratory and not accepted as authoritative assessment evidence. Mixed drills, section-test composition, free-text rubrics, a platform content editor and additional publication are future work; the current release provides single-activity Practice and Timed Drill.
