# Behavioral frameworks

Published platform frameworks and their principles/prompts are versioned and immutable. Publish a new version for a correction. General Software Engineering has 20 original competencies. Amazon Leadership Principles v1 has the 16 official principle names checked against https://www.amazon.jobs/content/en/our-workplace/leadership-principles on 2026-10-25; guidance, prompts and follow-ups are original PrepCraft content.

Versioned preparation templates select a framework through template_behavioral_frameworks. React does not switch on a company name. A user may choose a different published framework or create a private custom framework with 1–30 competencies. Platform content is read-only to normal users. Framework selection never deletes a story or rewrites mappings in another framework.
