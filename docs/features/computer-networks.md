# Computer Networks

Published concepts: TCP handshake, DNS caching, HTTP method semantics, TLS/HTTPS and cookies/sessions. Coverage also includes OSI/TCP-IP, IP/subnetting, UDP, sockets, REST, JWT, CORS, CDN and load balancing.

Request Journey distinguishes new connections from reuse, HTTP/1.1 and HTTP/2 over TCP from HTTP/3 over QUIC, and DNS/transport/TLS/HTTP phases. An ordered TCP activity is evaluated by exact sequence on the server. All diagram stages have textual equivalents.

Primary references: RFC 9293 (TCP), RFC 9110 (HTTP Semantics), and MDN protocol/cookie documentation. No signed JWT payload is described as encrypted by default.
