# Timing analytics

The default statistic is median. Mean is available as an explicit control. P25/P75 require eight eligible timings per bucket and P90 requires twenty. Missing buckets remain gaps. The mobile plot shows up to six recent buckets; View data retains the selected aggregate range.

Successful reported coding solves need at least thirty seconds. Behavioral retellings need fifteen seconds and a successful reported outcome. Submitted server-evaluated objective checks use their own cohort and positive durations. Failed coding solves contribute to outcome/time-spent evidence, not successful solve-time statistics. Pending, abandoned, invalid and below-threshold observations are disclosed as exclusions. Valid long attempts are retained.

Targets are captured source-policy targets. Target variance is the median of actual-minus-target pairs, not the difference of unrelated medians. No default target is supplied. First-hint latency sums item-focused intervals before the first reveal, excluding pauses and other items.

Best time requires an eligible successful timing. Manual prompts lack stable question identity; a first record does not prove the question was unseen. Repetition may influence timing. Objective confidence calibration requires ten evaluated observations overall and five per confidence bucket; coding self-reports never supply its correctness denominator.
