# Behavioral self-practice

Launch uses the existing Execution lifecycle and timestamp-authoritative timer. Relaxed practice has no target. Timed practice defaults to 120 seconds, accepts 60–900 seconds and counts down to an advisory target. At zero, timing continues for evidence while the display stays at zero; the user finishes their thought and explicitly ends. Pause is allowed. Browser sleep, refresh and wall-clock changes do not create a second timing authority.

Prepared text is initially hidden. Reveal outline records cue level 1 before returning truncated STAR sections; reveal full story records level 2. The maximum cue use cannot be reduced. Private notes never become cues. Working notes remain on the device. Finish stops timing before reflection.

Retelling outcome plus recorded cue use determines the shared result: independent, small hint, major hint or could-not-solve. Confidence, clarity, action specificity and result specificity are explicitly self-rated 1–5. The database rejects attempts to bypass these fields through the generic debrief endpoint. Completion is idempotent.

An attempt shorter than 15 focused seconds remains in Execution but contributes no meaningful-practice coverage, Behavioral history or Revision schedule. Early rehearsal preserves the shared spaced-recall interval rather than allowing repeated immediate practice to inflate it.
