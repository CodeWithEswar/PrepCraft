# Operating Systems

Release 1 publishes processes, threads, scheduling, synchronization and deadlocks. Outlines also cover foundations, memory, virtual memory and file systems.

Scheduler Lab implements bounded FCFS, non-preemptive SJF, SRTF and Round Robin with quantum 2. Arrival times, idle periods and ready queues are explicit. Completion/turnaround/waiting metrics are calculated from the resulting timeline, with an accessible table. Pure FIFO/LRU simulation is available and tested for further content publication.

Source reference: Operating Systems: Three Easy Pieces, https://pages.cs.wisc.edu/~remzi/OSTEP/. Original examples and explanations are authored for PrepCraft.
