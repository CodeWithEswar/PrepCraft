# Revision History

Every committed source attempt stores outcome, confidence, duration, revealed hint level, previous interval/date, resulting interval/date, reason and policy. The initial attempt is distinguished by a null prior interval; review_count excludes that initial scheduling event.

Retention Thread exposes the causal transitions. Memory Orbit provides keyboard/tap Popovers and a textual interval explanation. Its marker moves for 450ms; reduced motion updates immediately. Major assistance or failure needs reinforcement. Otherwise fewer than two consecutive independent recalls is Developing, 2–3 Stable, and at least 4 Strong. These are evidence bands, not percentages.

History is bounded to 30 rows per page, snoozes to the latest 20. Failed history loading does not disable starting a due review. Retired relationships retain evidence and can be restored. No client review edit/delete API exists.
