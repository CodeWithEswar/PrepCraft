# Behavioral Interview Preparation

Behavioral lives at /w/[workspaceSlug]/interview/behavioral and uses the Graphite, mineral and Smoked Sienna workspace design. Overview, Stories, Principles, Prompts, Practice, Coverage and History share one private portfolio. Preview examples are clearly illustrative and never seed a user account.

The portfolio supports explicit create/edit, title/summary search, status/type/confidence/freshness/competency filters, version conflicts, independent duplication, reversible retirement and bounded history. A story can support multiple framework competencies with one primary emphasis. Switching frameworks preserves stories, mappings and evidence.

Story Forge contains Situation, Task, Action, Result and Reflection, context, period, summary, type and private notes. Drafts may be incomplete; practice-ready status requires all four STAR sections. Save is explicit. Failed saves retain a browser-local draft and concurrent edits cannot silently replace a newer version. Local drafts contain private text; discard them on shared devices.

Story Prism changes the emphasis selected from the user's own mappings. It never rewrites facts. STAR Balance describes word composition and offers guidance; it is not a story-quality score. Evidence Thread displays entered responsibility, actions, result and reflection without generating metrics.

Practice is self-directed. There is no AI interviewer, voice/video capture, emotion/personality analysis or hiring prediction. Optional cues and four self-ratings are evidence of preparation, not an automated evaluation. See behavioral-practice.md and behavioral-coverage.md.

Today reads at most two metadata candidates and isolates a failed contribution. Planning opens the normal task editor with a story title and requires explicit save. Neither consumer writes Behavioral evidence. Shared Revision owns recall scheduling; Behavioral does not create a parallel reminder table. Behavioral attempts are excluded from DSA Mastery.

Current limits: custom frameworks support create/select but no publication editor; prompt content is platform-authored; the history query returns 30 rows plus a next-page lookahead; matrix columns show five recent filtered stories. No streak, generated story, readiness percentage or fabricated achievement is displayed.
