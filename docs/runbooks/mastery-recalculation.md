# Mastery Recalculation

1. Confirm workspace, user, pinned curriculum and policy/window. Do not export private source text. Check safe timing/status telemetry and the metadata-only live verification.
2. Reopen/refetch Mastery after a committed debrief or Revision review. Results are derived on demand; there is no manually editable mastery score, job acknowledgement or projection to patch.
3. If evidence is unassigned, use Organize evidence or select a canonical topic in the next Execution session. Never infer historical topic identity from a title. Incorrect existing attribution requires an explicit reviewed repair with provenance; do not silently reassign it.
4. Missing timing is expected until at least two independently solved Interview attempts have real per-item targets. Missing retention is expected until real spaced reviews exist. Pending reflections, abandonment and under-30-second records do not count.
5. If historical comparison fails, keep the current interpretation and retry later. If a source aggregate violates validation, diagnose counts and constraints; never substitute zero. Recompute through the current versioned policy after an additive repair.
6. Run portable policy tests, test:mastery:db, cross-workspace checks, responsive/browser tests and live metadata verification after changes. Docker-backed Supabase extension checks remain CI work on this host. No Cloudflare/D1/KV/Cron or full Readiness/Analytics engine is introduced.
