# Recovering an active session

1. Open Practice in the same workspace and choose Continue session. Refresh resolves the stored timestamps and deadline; it does not create another session.
2. If another tab changed the session, restore the latest server state. Review any conflicting local working draft before explicitly keeping it or using the server draft.
3. Practice can resume a persisted pause. Interview/OA cannot pause; if the deadline passed, resolve finalizes at that deadline and opens pending reflection.
4. If offline, keep the device draft and reconnect. Do not report a mutation successful without a server response. Late OA drafts remain unsubmitted and can only be copied for personal review.
5. A completed session with pending reflection can reopen its Attempt Debrief from history or Today. Do not recreate the attempt to recover a form.
6. To end unwanted active work, use the explicit End session confirmation. The server preserves saved notes/time without manufacturing an outcome.

For operators: verify workspace membership, session owner/status/version, deadline, open focus interval and request event identity with appropriately scoped access. Use the normal transactional RPC to resolve/finish; do not hand-edit pause totals, extend an OA deadline or delete evidence to release a unique index. If workspace access was intentionally disabled/archived, restore access only through the existing authorized workspace workflow. No service-role credential should be pasted into a browser or client log.
