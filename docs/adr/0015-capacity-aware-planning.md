# 0015: Preparation plans respect explicit capacity

Status: Accepted

Planning resolves date overrides before recurring availability, then uses the workspace's configured study days and daily budget. Rest is explicit. Available minutes, active planned estimates, remaining estimates and recorded focus are separate quantities.

Required work that cannot fit produces a visible capacity conflict; it never becomes a falsely achievable plan. Fixed obligations are protected and atomic work is not squeezed into smaller gaps. A reviewed proposal is required before generated work becomes active.

Uniform seven-day allocation and an opaque health score were rejected. The consequence is deterministic, testable distribution with understandable overload and explicit user decisions.
