# 0020: Practice, Interview and OA share one execution engine

Status: Accepted

A versioned policy controls timer direction, target bounds, pause, hints, auto-finish, multiple questions and communication support. Practice counts upward and may pause; its target is advisory. Interview is self-directed technical practice with a countdown, phase rail, self-reported checklist, no pause and at most two structured hints. OA has one round countdown, multiple items, no pause and no hints. Policy is frozen by the server from the chosen mode, never trusted from query parameters.

The audit found no Question Library, Code Runner, Revision or Mastery domain. Execution therefore accepts explicit user-provided question snapshots or authorized custom planning tasks, with optional structured hints. These are session-local source snapshots, not a new question catalog. Canonical question resolution remains an explicit future source contract. Code is editable and persisted; no evaluation is claimed without a runner.
