# Median-first timing

Status: Accepted · 2026-10-26

Median is the default timing statistic because a few long valid sessions should not dominate the typical-time headline. Mean remains an explicit control. PostgreSQL continuous percentiles preserve long valid observations; thresholds gate each distribution.

Compare only homogeneous, sufficient, complete equal calendar-day cohorts. Source targets are captured values, and variance uses actual pairs. Timing is preparation evidence rather than an objective coding or hiring score.
