# Responsive chart reduction

Status: Accepted · 2026-10-26

Mobile reorganizes Analytics rather than shrinking the desktop grid. It uses one chart per row, a bottom filter drawer, fewer displayed timing buckets, an optional range band and list-first relationships. Full selected-period aggregates remain in data tables.

The page cannot horizontally overflow. Internal wide tables may scroll in labeled focusable containers. Desktop insight rails move below evidence when plot area becomes constrained.
