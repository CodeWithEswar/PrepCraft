# Behavioral coverage without a Mastery score

Status: Accepted

Date: 2026-10-25

Decision: Coverage remains a derived, reasoned state from mappings, manual story status, practice recency, cues and self-ratings. STAR attempts are excluded from DSA Mastery. Missing evidence stays visible rather than becoming a fabricated weakness or readiness percentage.

Consequences: bounded, private source evidence and explainable UI. See the Behavioral feature, architecture and authorization documents for implementation contracts and limits.
