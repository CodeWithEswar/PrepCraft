# Restrained Analytics palette

Status: Accepted · 2026-10-26

Use Graphite/ivory surfaces, Smoked Sienna primary evidence and neutral reference series. Reserve semantic status colors for supported source states, paired with text. Differentiate chart series through line styles, shapes and labels rather than a universal rainbow.

Near-solid chart surfaces preserve legible axes in both themes. Avoid chart glow, heavy blur and animated decoration. The design audit covers contrast and both theme variants.
