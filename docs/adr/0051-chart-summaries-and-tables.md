# Accessible chart summaries and tables

Status: Accepted · 2026-10-26

Charts must remain understandable without hover, color discrimination or SVG interpretation. Every frame carries a descriptive question, readable summary, Evidence Lens and data table. Scatter, calendar and relationship selections have HTML control paths.

Failed plots preserve fallback content. Scrollable tables and drawers are keyboard focusable. Automated WCAG audits are supplemented by interaction checks and honest manual screen-reader limitations.
