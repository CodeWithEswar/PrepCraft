# Evidence Lens for derived metrics

Status: Accepted · 2026-10-26

Each metric exposes definition, source, period, sample, policy, exclusions and interpretation limits in a shared Evidence Lens. Current source states are distinguished from selected-period observations. Unavailable measurements remain missing.

The lens uses a desktop dialog/mobile drawer and never loads private code, answer text or story bodies. Provenance is a product control, not an implementation-only tooltip.
