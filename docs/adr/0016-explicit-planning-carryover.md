# 0016: Carryover is a decision, not a midnight side effect

Status: Accepted

Unfinished work remains visible until explicitly carried, rescheduled, skipped or cancelled. Moving creates a planning projection with lineage to the prior projection while preserving the same underlying source. Repeated carryovers remain countable. Completed source work cannot be casually reopened.

Silent completion, silent dropping and automatic Monday injection were rejected. Week close preserves a review snapshot and requires a decision for unfinished required work.
