Meaningful history excludes sub-15-second attempts.

Revision uses the first Behavioral prompt item as the stable story recall identity. Later practices link to that Revision item. A Revision launch binds the current story snapshot and routes through the generic session URL to Behavioral practice. Early rehearsal uses the existing no-advance policy. Retirement/restoration invokes Revision's own command authority.

Mastery aggregate/spine queries explicitly exclude Behavioral bindings so STAR practice does not become DSA solving evidence. Today reads metadata candidates through src/lib/behavioral/read-candidates.server.ts with failure isolation and rest-day suppression.
