# Mastery Evidence Ownership

Execution owns sessions, immutable reflected attempts and explicit canonical topic attribution. Revision owns learning identities, review outcomes, intervals and dates. Templates own the pinned effective curriculum. Mastery reads their authorized metadata and produces derived interpretations; it never changes their schedules, scores or content.

The current repository has no canonical Question Library or Mistake Journal. Topics are associated explicitly in the Execution lobby or Organize evidence. Revisions resolve topic attribution from the original learning identity, preventing repeated review snapshots from creating new question coverage. Pattern association comes from a committed debrief. No title matching or cross-workspace evidence borrowing occurs.

The source queries omit question bodies, code, scratchpads, STAR stories, notes and reflections. They return outcome/difficulty/timing/confidence/identity aggregates, plus bounded unassigned titles. Operational logs contain status codes, timings and counts. New source adapters must preserve provenance and ownership.
