# Geist fonts

Unmodified Latin variable fonts copied from Next.js 16.4.3's bundled Geist assets. Upstream: https://github.com/vercel/geist-font. Copyright and SIL Open Font License are in OFL.txt.

The app self-hosts the same Geist and Geist Mono families to make development and builds independent of Google Fonts requests. Font display remains swap.
